## 🧩 About This Repository

This repository holds my solutions to problems from the **[Beecrowd](https://www.beecrowd.com.br/)** online judge. It's a running log of practice — covering basic input/output, conditionals, loops, arrays, math, and logic-building problems, solved as I work through them.

The repository is intentionally **language-flexible**: a solution here may be written in whichever language best fits the problem or whatever I'm practicing at the time. The structure below stays the same regardless.

---

## 📋 File Naming Convention

Every solution file follows this pattern:

```
PROBLEM_ID.ext   (Category_ProblemID_ProblemName)

Example:
1000.xx  (Beginner_1000_Hello World!)
```

Where `.ext` is whichever language's file extension the solution was written in.
